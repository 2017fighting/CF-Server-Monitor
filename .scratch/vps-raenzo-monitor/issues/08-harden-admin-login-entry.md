# 08: 后台登录入口加固

**What to build:** 未登录的自动化请求访问后台入口时被拦住，正常浏览器仍能登录；探针上报与公开大盘接口不受影响。当前后台登录口对公网完全敞开，且站点是公开访问的。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 不带登录 Cookie 的脚本访问后台入口时被质询或拒绝
- [ ] 正常浏览器登录、刷新、登出流程不受影响
- [ ] 探针上报仍成功，大盘公开接口仍可用
- [ ] 加固前后各记录一次误拦检查，确认没有误伤探针与已登录浏览器
