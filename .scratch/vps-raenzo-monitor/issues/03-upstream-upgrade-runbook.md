# 03: 上游升级流程：一条路到线上，带冒烟与回滚

**What to build:** 上游发布新版本后，能从当前线上版本升到新版，并在升级后几分钟内用命令确认「面板正常 + 探针仍在线」；出问题能一步退回上一版。流程写进仓库文档，换台机器、换个人也能照着做完。

**Blocked by:** 01（Workers 部署 workflow 与线上配置对齐）、02（`npm test` 在无 sudo 环境跑绿）

**Status:** ready-for-agent

- [ ] 文档记录完整流程：添加 upstream remote、拉取目标提交、查看版本差异、测试、构建、部署、冒烟
- [ ] 部署前记录当前 Worker 版本 ID；回滚命令与回滚后的验证方式一并写进文档
- [ ] 冒烟检查至少覆盖：首页 200、`/api/servers` 中服务器全部在线、探针上报接口正常接收
- [ ] 按流程做一次「同版本重部署」演练，并通过全部冒烟项
- [ ] 文档写明 Worker 版本与 Agent 版本的最低兼容要求
